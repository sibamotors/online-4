# سیبا موتور — مدیریت کار تیمی

برنامهٔ وب (کانبان، تقویم، گانت، اسکرام، پیام‌رسان، گزارش، لاگ فعالیت) با **TanStack Start + React + PostgreSQL**؛ فارسی و انگلیسی.

## راه‌اندازی روی سرور
راهنمای قدم‌به‌قدم: [`docs/DEPLOY-FA.md`](docs/DEPLOY-FA.md)

نیازمندی‌ها: **Node.js 22.12 یا بالاتر** و **PostgreSQL**.

```bash
cp .env.example .env     # DATABASE_URL و SESSION_SECRET را پر کنید
npm ci
npm run build
npm start                # ابتدا migration دیتابیس، بعد سرور (پورت پیش‌فرض ۳۰۰۰)
```

### متغیرهای محیطی (فایل `.env`)
| نام | توضیح |
|---|---|
| `DATABASE_URL` | آدرس PostgreSQL (الزامی) |
| `SESSION_SECRET` | حداقل ۳۲ کاراکتر تصادفی؛ برای امضای کوکی ورود (الزامی) |
| `ADMIN_BOOTSTRAP_USERNAME` / `ADMIN_BOOTSTRAP_PASSWORD` | ساخت اولین ادمین (فقط وقتی ادمین فعالی وجود ندارد) |

## امنیت (خلاصه)
- نشست سمت سرور با کوکی `HttpOnly` امضاشده؛ هویت کاربر هرگز از ورودی مرورگر خوانده نمی‌شود.
- همهٔ توابع سرور با middleware احراز هویت/ادمین/دسترسی محافظت می‌شوند.
- رمزها با scrypt هش می‌شوند؛ ۵ تلاش ناموفق = قفل ۱۵ دقیقه‌ای.
- فایل‌ها فقط برای فرستنده/گیرندهٔ همان پیام قابل دانلود هستند.
- هدرهای امنیتی (CSP، HSTS، …) روی همهٔ پاسخ‌ها.

## توسعهٔ محلی
```bash
npm ci
npm run dev               # http://localhost:8080 (بدون DATABASE_URL از دیتابیس محلی PGlite استفاده می‌کند)
npm run typecheck && npm run lint && npm test
```

## نکات
- فقط **یک** نمونه از برنامه اجرا شود (قفل نوشتن دادهٔ فضای کار داخل همین پروسه است).
- مهاجرت‌ها در `migrations/` هستند و در هر استارت خودکار اجرا می‌شوند.
- ویژگی‌های اضافه‌شده: [`docs/NEW-FEATURES-FA.md`](docs/NEW-FEATURES-FA.md)
